  • P2无人机分电板
  • 概述

高精度DroneCAN分电板(PDB)，是专为Y3垂起/双发固定翼无人机动力系统打造的专属解决方案，同时兼容Ardupilot、PX4主流飞行控制平台。它以一体化设计整合核心功能，无需额外搭配设备，既能简化装机流程，又能稳定支撑该类机型飞行作业的动力需求，降低使用门槛，是Y3垂起/双发固定翼无人机动力系统的高适配选择。

核心硬件，性能拉满 主控芯片:STM32L431xC，256KB Flash，运算稳定高效 20位超精密，精准监控电流/电压/功率/能量/充电 采样芯片:INA228AQDGSRQ1(AEC-Q100车规级)，85V 耐压、 陶瓷电容，耐用性与稳定性双保障 关键元件:Vishay金属一体成形电感、车规级合金采样电阻、Murata陶瓷电容，

核心功能，即插即用 配Y3垂起/双发固定翼动力监控需求 基于DroneCAN协议，无需校准即可输出高精度电压电流数据，适 兼容Ardupilot、PX4主流飞行控制平台，适配性广，装机无兼容性顾虑 电流计+多路电压供电一体化设计，减少机身布线，提升动力系统集成度

电气规格，实力抗造 输入电压:12.8~25.8V 输入电流:0~120A(大电流适配，满足双发固定翼动力供电需求) 采样精度:电池电压+0.1%，电池电流±2%，精准反馈动力状态 工作温度:-10~60°C(适应多场景飞行，无惧复杂环境) 尺寸:47x58x12mm(小巧易安装，适配Y3垂起固定翼紧凑机身布局)

多接口供电，满足需求 口(Molex 5025850670) 1.飞控供电:5.0V(max4.5A，持续3A)，标准PX4 CAN POWER接 2.舵机供电:8.4V/5.1V舵机电压需求 可调(max10A，持续6A)，灵活适配不同 续3A），满足不同设备供电需求 3.机载计算机供电:5.0V(max4.5A,持续3A)、12.0V（max4A,持续3A）供电，满足不同设备供电需求。
