# SwiftWing R1 RTK 移动端

SwiftWing R1 RTK 使用 UM982 和双天线解算位置、速度与航向，ESP32-S3 负责设备配置、有效性检查和接口转发。日常经 DroneCAN 连接 PX4 / ArduPilot 飞控，原生 USB 和 Wi-Fi 网页用于管理。设备没有外置磁罗盘。

双天线用于测量机头方向；固定地面基站通过外部差分改善位置。位置 RTK Fixed、双天线有效航向和飞控估计器采用航向，需要分别确认。

## 支持的功能与前置条件

| 功能 | 开始使用前需要什么 | 操作位置 |
| --- | --- | --- |
| GNSS 位置 / 速度 | 有效供电，ANT1 接匹配的有源天线并有合适卫星条件 | [硬件安装](硬件安装.md) |
| 双天线机头航向 | ANT1 / ANT2 同型号天线固定；实测基线与偏角已保存，启用 HDG_ENABLE，飞控协议兼容 | [QGC 配置](QGC配置移动端.md)、[航向确认](起飞前检查.md#rtk-heading) |
| CAN 向飞控输出定位与航向 | 正确线序、供电和终端；两端同速率，飞控已启用 DroneCAN GNSS | [PX4](PX4飞控参数.md) / [ArduPilot](ArduPilot飞控参数.md) |
| 接收差分、获得 RTK 解 | SwiftWing / 第三方基站或网络服务提供兼容的 RTCM3，QGC 注入目标飞控，飞控转发 CAN，观测条件合适 | [差分来源与检查](差分与Wi-Fi后台.md#correction-sources) |
| USB 配置设备 | 移动端主板数据 USB 接电脑，SwiftWing QGC 识别到正确设备，串口未被其他程序占用 | [USB 配置](QGC配置移动端.md) |
| 设备热点网页 | 无线及热点当前已开启；电脑 / 手机连接本移动端热点，再访问 192.168.4.1 | [热点规则与入口](差分与Wi-Fi后台.md#wireless-rules) |
| 局域网网页 | 设备已保存可用的 2.4 GHz 网络，实际已取得 IP，主机同网，且无线没有进入省电关闭 | [USB 预配置与后台](差分与Wi-Fi后台.md#web-backend) |
| 定位 / 航向只读诊断 | 后台可达，读取最近报文并核对新鲜度；不要求无线高级维护 | [日志与诊断](日志与常见问题.md#gnss-diagnostic) |
| 掉电保留日志 | 设备正常供电并处于记录状态；导出时需有可达的设备后台 | [记录与导出](日志与常见问题.md) |
| 固件升级 | 正确的应用镜像、稳定供电和管理连接；无线升级须启用无线高级维护 | [升级操作](日志与常见问题.md) |
| 飞控提示音 / 状态 | BEEP_ENABLE 开启，且所用飞控发送本设备支持的 CAN 状态或音调消息 | [设备参数](QGC配置移动端.md) |

**正常定位不要求配置移动端 Wi-Fi，也不要求一直插移动端 USB。** 基站 UDP 先进入 QGC，再经飞控 CAN 到移动端；移动端的 Wi-Fi 是管理入口，不直接接收基站 UDP / TCP 差分。本板没有外置磁罗盘，移动端角色不运行基站温控风扇策略。

## 先选你的使用场景

1. **首次装机、换天线或未知配置**：先用移动端自己的 USB 在 QGC 核对角色、基线、偏角和 CAN，再配置飞控。
2. **只需要日常定位 / 航向**：保留 CAN 与供电，将所选差分来源接入 QGC 并向飞控注入；配套基站日常优先 UDP，移动端 USB、Wi-Fi 都是可选的。
3. **还需要网页后台**：先判断无线是否可用。已识别飞控并正常 CAN 交互时，无线通常关闭；先经 USB 启用无线后台，或长按 BOOT 开临时窗口，再访问热点 / LAN。

**已保存 Wi-Fi 不等于后台会一直在线。** 自动开无线、自动关热点以及两种维护开启方式的条件，统一见本产品的[无线与热点规则](差分与Wi-Fi后台.md#wireless-rules)。

## 搭配哪一种基站

本移动端可以按下列路线接入差分；是否适配取决于 RTCM 报文和链路能力，不能只凭厂家名称判断。

| 差分来源 | 前置条件 | 按哪一段操作 |
| --- | --- | --- |
| SwiftWing R1-G 基站 | 基站已完成配置，日常通过 UDP 将有效 RTCM 送入 QGC | [配套基站路线](差分与Wi-Fi后台.md#swiftwing-base) |
| 其他厂家本地基站 | 用该厂家软件完成建站；能向电脑输出本移动端支持的标准 RTCM3 | [第三方 USB / UDP / TCP 接入](差分与Wi-Fi后台.md#third-party-base) |
| CORS / NTRIP 网络差分 | 有可用服务、授权账号与挂载点，QGC 主机可联网；需要 GGA 的服务还要有有效位置上报 | [NTRIP 接入](差分与Wi-Fi后台.md#ntrip-input) |

换基站时，移动端仍按本手册配置基线、CAN 和飞控；第三方基站的建站、端口和报文用其厂家工具配置。SwiftWing 参数页和网页地址只管理 SwiftWing 设备。**差分来源改变，不会替代本移动端的双天线航向设置。** 上述为按接口条件整理的接入方法，具体第三方型号仍需实机确认。
