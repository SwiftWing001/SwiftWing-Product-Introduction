# SwiftWing R1-G RTK 产品介绍

SwiftWing R1-G RTK 是用于生成和分发 GNSS 差分数据的本地 RTK 基站。设备采用 UM982 接收机和 ESP32-S3 主控，支持浏览器管理、USB 双串口、2.4 GHz Wi-Fi、温度监测、基站风扇控制和日志导出。选配 2S 18650 供电板支持电池供电、充电与低压报警。

支持两种建站方式：

- **自主测量基站**：在没有可靠已知坐标的地点，固定天线并由接收机进行自主平均建站。
- **已知坐标基站**：输入经过核验的基站坐标，用于固定点或需要保持统一参考坐标的作业。

主要差分输出方式为 USB、Wi-Fi UDP 和原始 TCP 服务端，可按需同时启用。默认路由 AUTO 在有有效 QGC USB 会话时优先 USB，否则走 UDP。基站提供参考数据，接收端还需要正确接入差分、具备合适的卫星观测条件，并完成自身配置。

本手册只介绍基站，不包含机载移动端的双天线航向、飞控 EKF 或磁罗盘配置；相关配置见 [移动端快速上手](../SwiftWing_R1_RTK_移动端/快速上手.md)。
