# SwiftWing R1-G RTK 产品介绍

SwiftWing R1-G RTK 是用于生成和分发 GNSS 差分数据的本地 RTK 基站。设备采用 UM982 接收机和 ESP32-S3 主控，支持浏览器管理、USB 双串口、2.4 GHz Wi-Fi、温度监测、基站风扇控制和日志导出。选配 2S 18650 供电板具备电源开关、匹配 12 V 档的 PD 快充输入、2S 充电、两节被动均衡、过充等保护电路及低压报警；具体操作和时间条件见[供电与充电](供电与充电.md)。

支持两种建站方式：

- **自主测量基站**：在没有可靠已知坐标的地点，固定天线并由接收机进行自主平均建站。
- **已知坐标基站**：输入经过核验的基站坐标，用于固定点或需要保持统一参考坐标的作业。

主要差分输出方式为 USB、Wi-Fi UDP 和原始 TCP 服务端，可按需同时启用。默认路由 AUTO 在有有效 QGC USB 会话时优先 USB，否则走 UDP。基站提供参考数据，接收端还需要正确接入差分、具备合适的卫星观测条件，并完成自身配置。

日常建议：**主板 USB 完成首次配置后，优先用无线 UDP 获取 RTCM。** 电池或供电板 USB 都可通过 SW1 给基站供电，接充电器补电时仍可用 UDP；主板 USB 也支持临时获取 RTCM。主板检测温度并按阈值启停风扇，本手册设置为 **35 °C 开启、30 °C 停止**；已有设备需修改参数并保存。首次使用按[快速上手流程](快速上手.md)逐步完成。

本手册介绍基站侧的建站和差分输出。机载使用 SwiftWing 移动端时，继续按[移动端快速上手](../SwiftWing_R1_RTK_移动端/快速上手.md)配置；机载使用其他厂家产品时，按下方接口选择路线，其天线、航向与飞控参数使用对应厂家的教程。

## 支持的功能与前置条件

| 功能 | 开始使用前需要什么 | 操作位置 |
| --- | --- | --- |
| 自主测量建站 | 基站角色、ANT1、可靠供电；天线固定在开阔处，等待参考与观测就绪 | [基站模式](基站模式与参数.md) |
| 固定坐标建站 | 可靠的天线参考点坐标与椭球高，固定坐标已确认有效，天线位置不变 | [坐标填写](基站模式与参数.md) |
| UDP 差分（日常首选） | 独立供电、SW1 开启；基站与 QGC 主机同一 2.4 GHz 局域网，目标 IPv4 和 13320 端口匹配 | [UDP 设置](Wifi输出差分.md) |
| USB 配置 / 备用 RTCM | 主板原生数据 USB、SwiftWing QGC；获取 RTCM 还需基站角色及有效差分，普通改参不需要先建站成功 | [USB 接入](USB与地面站输出差分.md) |
| 原始 TCP 差分 | 有效局域网，手动路由启用 TCP 出口，客户端连接基站实际 IP:2101 | [TCP 设置](Wifi输出差分.md#tcp-output) |
| 多网络 / 固定 IP | 保存外部 Wi-Fi 凭据；最多 5 组，静态地址须符合所在网段且不冲突 | [局域网设置](设备后台参数修改.md) |
| 热点 / LAN 网页 | 无线当前开启；热点访问需连接设备热点，LAN 访问需实际取得 IP 且主机同网 | [入口选择与热点规则](设备后台参数修改.md#wireless-rules) |
| 向 SwiftWing / 第三方移动端提供差分 | 接收端支持本基站 RTCM3 报文；经飞控时还需其驱动支持向目标 CAN / 串口 GPS 注入 | [按移动端选择路线](USB与地面站输出差分.md#third-party-rover) |
| 温度监测 / 自动风扇 | 基站角色、NTC 正常，风扇接 FAN+ / FAN−，保存 FAN_ON_C=35、FAN_OFF_C=30；35 °C 开、30 °C 停 | [温控步骤](供电与充电.md#cooling) |
| 电池 / 外电供电与充电 | 选配 2S 供电板、电芯匹配；充电源匹配 12 V 档，给主板供电时 SW1 开启 | [PD、均衡与保护](供电与充电.md#charging) |
| 日志与只读诊断 | 设备在记录；读取 / 导出时后台可达，普通日志不要求无线高级维护 | [日志与诊断](日志升级与恢复.md) |
| 固件升级 / 原始指令 | 正确镜像或指令、稳定管理连接；无线执行前启用无线高级维护 | [维护操作](日志升级与恢复.md) |



## 搭配哪一种移动端

| 移动端类型 | 前置条件 | 差分路线与教程 |
| --- | --- | --- |
| SwiftWing R1 CAN 移动端 | 本移动端与飞控已按配套参数配置 | 基站 → QGC → 飞控 → CAN，见[移动端教程](../SwiftWing_R1_RTK_移动端/快速上手.md) |
| 其他厂家 DroneCAN 移动端 | 厂家支持当前飞控版本、DroneCAN 定位及 RTCM 接收 | 基站 → QGC → 飞控 → CAN，见[第三方移动端接入](USB与地面站输出差分.md#third-party-rover) |
| 其他厂家串口 RTK 移动端 | 飞控 GPS 串口驱动支持该型号及差分注入，线序 / 电平正确 | 基站 → QGC → 飞控 → GPS 串口，见[第三方移动端接入](USB与地面站输出差分.md#third-party-rover) |
| 自带原始 TCP / UDP 差分客户端的设备 | 能直接接收本基站的原始 RTCM3，且双方局域网互通 | 可直接接收，见[原始网络接入条件](USB与地面站输出差分.md#direct-network-rover) |

本基站默认输出 `1006 / 1033 / 1074 / 1084 / 1094 / 1124`。使用前核对对方接收机支持这些报文及其星座 / 频点；若对方要求额外报文，不能把默认输出视为已满足。基站的 RTCM 改善位置，**不会给单天线移动端增加双天线机头航向**。具体第三方型号仍需联调，本文不把接口支持写成已实测兼容。

首次使用从[基站快速上手](快速上手.md)开始；需要逐项查阅时进入[详细使用说明](详细使用说明.md)。主板逐针定义见[硬件接口与线序](../RTK通用/硬件接口与线序.md)，各接口输入输出见[接口数据与差分链路](../RTK通用/接口数据与差分链路.md)。
