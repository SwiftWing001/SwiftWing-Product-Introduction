SwiftWing R1-G RTK 产品介绍

SwiftWing R1-G RTK 是用于生成和分发 GNSS 差分数据的本地 RTK 基站。设备采用 UM982 接收机和 ESP32-S3 主控，支持浏览器管理、USB 双串口、2.4 GHz Wi-Fi、温度监测、基站风扇控制和日志导出。选配 2S 18650 供电板具备电源开关、匹配 12 V 档的 PD 快充输入、2S 充电、两节被动均衡、过充等保护电路及低压报警；具体操作和时间条件见供电与充电。

支持两种建站方式：

  • 自主测量基站：在没有可靠已知坐标的地点，固定天线并由接收机进行自主平均建站。
  • 已知坐标基站：输入经过核验的基站坐标，用于固定点或需要保持统一参考坐标的作业。

主要差分输出方式为 USB、Wi-Fi UDP 和原始 TCP 服务端，可按需同时启用。默认路由 AUTO 在有有效 QGC USB 会话时优先 USB，否则走 UDP。基站提供参考数据，接收端还需要正确接入差分、具备合适的卫星观测条件，并完成自身配置。

日常建议：主板 USB 完成首次配置后，优先用无线 UDP 获取 RTCM。 电池或供电板 USB 都可通过 SW1 给基站供电，接充电器补电时仍可用 UDP；主板 USB 也支持临时获取 RTCM。主板检测温度并按阈值启停风扇，本手册设置为 35 °C 开启、30 °C 停止；已有设备需修改参数并保存。首次使用按快速上手流程逐步完成。

本手册介绍基站侧的建站和差分输出。机载使用 SwiftWing 移动端时，继续按移动端快速上手配置；机载使用其他厂家产品时，按下方接口选择路线，其天线、航向与飞控参数使用对应厂家的教程。

支持的功能与前置条件

功能 开始使用前需要什么 操作位置
自主测量建站 基站角色、ANT1、可靠供电；天线固定在开阔处，等待参考与观测就绪 基站模式
固定坐标建站 可靠的天线参考点坐标与椭球高，固定坐标已确认有效，天线位置不变 坐标填写
UDP 差分（日常首选） 独立供电、SW1 开启；基站与 QGC 主机同一 2.4 GHz 局域网，目标 IPv4 和 13320 端口匹配 UDP 设置
USB 配置 / 备用 RTCM 主板原生数据 USB、SwiftWing QGC；获取 RTCM 还需基站角色及有效差分，普通改参不需要先建站成功 USB 接入

多网络 / 固定 IP 保存外部 Wi-Fi 凭据；最多 5 组，静态地址须符合所在网段且不冲突 局域网设置

什么时候先用 USB 配置后台

  1. 第一次使用、网络没配好或实际角色不清楚：先接主板 USB，用 QGC 保存基站角色、建站参数、外部 Wi-Fi 和 UDP 目标。
  2. 配置后日常作业：先开启 SW1 并确认供电，再拔掉主板数据 USB，使用 UDP。接供电板 USB 充电不会变成 USB 数据链路。
  3. 需要打开网页：无线 UDP 工作且已连上路由器时，直接访问实际 LAN IP；没有可用 LAN 时，可连接设备热点。热点和 LAN 的显示取决于当前网络状态，不要求同时存在。
  4. USB 配置时热点消失：AUTO 的有效 QGC USB 会话可能关闭无线；可在 QGC 点“启用无线后台”，或使用 BOOT 临时窗口。具体条件见本产品后台说明。

搭配哪一种移动端

移动端类型 前置条件 差分路线与教程
SwiftWing R1 CAN 移动端 本移动端与飞控已按配套参数配置 基站 → QGC → 飞控 → CAN，见移动端教程
其他厂家 DroneCAN 移动端 厂家支持当前飞控版本、DroneCAN 定位及 RTCM 接收 基站 → QGC → 飞控 → CAN，见第三方移动端接入
其他厂家串口 RTK 移动端 飞控 GPS 串口驱动支持该型号及差分注入，线序 / 电平正确 基站 → QGC → 飞控 → GPS 串口，见第三方移动端接入
自带原始 TCP / UDP 差分客户端的设备 能直接接收本基站的原始 RTCM3，且双方局域网互通 可直接接收，见原始网络接入条件

本基站默认输出 1006 / 1033 / 1074 / 1084 / 1094 / 1124。使用前核对对方接收机支持这些报文及其星座 / 频点；若对方要求额外报文，不能把默认输出视为已满足。基站的 RTCM 改善位置，不会给单天线移动端增加双天线机头航向。具体第三方型号仍需联调，本文不把接口支持写成已实测兼容。

首次使用从基站快速上手开始；需要逐项查阅时进入详细使用说明。主板逐针定义见硬件接口与线序，各接口输入输出见接口数据与差分链路。
