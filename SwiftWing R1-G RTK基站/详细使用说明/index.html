SwiftWing R1-G RTK 详细使用说明

更新日期：2026-11-13。适用 SwiftWing-UM982 V1.0 基站，操作以设备固件 0.1.23 / 0.1.24 系列、SwiftWing QGC Windows 0.1.0 build8 为依据；选配 2S 供电板按 2026-11-12 设计说明。

先按流程使用，再按功能查阅

第一次操作先打开快速上手：页面顶部有精简流程图，下方按安装软件、准备设备、USB 首次配置、日常 UDP、检查移动端、温控和关机七步展开。电池或供电板 USB 均可供电；补电时仍优先 UDP，主板 USB 用于配置和备用 RTCM。

需要核对时间和充电功能时，看供电与充电：已有运行约 4.5 小时至报警的历史样机记录；关开关后的完整待机上限尚未测得，无负载超过 7 天的记录单独注明条件。

  1. 快速上手：软件下载、USB 接入、自动建站、局域网及转发。
  2. 硬件功能与接口、主板线序、供电与充电：接线与电源。
  3. 接口数据与差分链路：每个接口的数据方向和完整链路。
  4. QGC 地面站参数修改或设备后台参数修改：选择设备、修改与保存。
  5. 基站模式与参数、设备参数参考：自主测量、已知坐标和各功能参数。
  6. USB 与地面站输出差分、Wi-Fi 输出差分：USB、UDP 和原始 TCP。
  7. 日志、升级与恢复：会话导出、应用镜像升级与两个恢复入口。

机载使用 SwiftWing 时，CAN、双天线和飞控参数按移动端教程；机载使用其他厂家时，先按第三方移动端路线选择 CAN / 串口 / 原始网络入口，再使用对应厂家参数。第三方基站向 SwiftWing 移动端送差分的反向搭配，见移动端的第三方基站接入。

实际版本和保存参数以设备读回为准。通用固件新配置默认是移动端，恢复设备参数后须重新选择基站；正常保参升级不会自动改变原基站角色。配置成功、差分传输、移动端固定解和飞控航向融合需要分别确认。

每次作业检查

  1. ANT1 固定、无遮挡；基站和支架没有在建站后移动。自动测量或已知坐标模式与现场一致。
  2. 电池与电源连接正确，无低压报警。需要 SW1 关机时，核对主板 USB/CAN 是否还提供外电。
  3. QGC 选对基站硬件码，角色、站号、坐标及路由读回正确。
  4. 接收机显示 RTCM 就绪，QGC 有效帧增长、CRC 没有持续报错、帧龄新鲜。
  5. 差分注入对象和反馈绑定符合本轮目标，移动端收到 RTCM，目标 GPS 达到本次任务要求的解状态。绿色基站图标不能单独作为放飞判据。
  6. 无线时检查 QGC 主机 IP、UDP 目标、端口、信号和实际可达性；USB 测试时不被 AUTO 切路误导。
  7. 板温、风扇及告警状态正常。
  8. 需要留档时及时停止并导出记录，异常附现场说明。

常见问题

现象 排查要点
接 USB 不识别基站 是否误插供电板充电口；检查 RTK 数据线、实际 USB 方向、串口占用及设备身份
等待 valid RTCM3 查角色、测量条件、RTCM 就绪、配置/RTCM 接口；不要盲改 UM982 波特率
插 USB 后 UDP 没数据 AUTO 可能优先 USB 并关无线；断主板数据 USB 或明确手动 UDP
TCP 连不上 手动模式启 TCP、正确基站 IP、端口、同网和防火墙；不是 NTRIP 账户问题
Wi-Fi 连上但 QGC 收不到 查 QGC 电脑目标 IP、UDP 监听开关/端口、防火墙及客户端隔离
显示设备名但无后台 IP 查真实 LAN 连接和无线省电；未知 UDP 身份不一定能显示本设备后台
绿图标但飞控没 Fixed 图标只证明其接收条件；逐段查飞控转发、CAN、移动端差分龄和 GNSS 质量
第三方移动端收不到差分 按其 CAN / GPS 串口核对驱动和 RTCM 注入能力；不能照抄 SwiftWing 网页或设备参数
第三方只有 NTRIP 客户端，连不上本基站 2101 此口是原始 TCP；用 QGC / 飞控转发，或另设合适的 NTRIP 中转，不把端口相同当成协议相同
其他地面站打开 USB 仍没有 RTCM 对方不一定支持 SwiftWing 会话；预先保存手动 USB 出口并选 RTCM CDC1，见其他地面站说明
风扇一直转 核对温度/阈值，FAN- 是否额外接 GND；不要用电池温度猜板温
关 SW1 后 RTK 还运行 主板 USB 或 CAN 仍可能供电；关的是 XT30 支路，不切其他电源
绿充电灯但单节不一致 绿灯不等于均衡合格；分别测两节及同参考点总压，核对充电/均衡动作

版本与参考依据

依据本项目主板网表、固件参数与接收机配置、QGC B8 配置和差分转发实现整理。供电测量原记录保存在供电与充电中。可参考零一地面 RTK 建站教程理解建站和差分接收流程；本板由 ESP32 自动配置 UM982，不照搬其 GPS_AUTO_CONFIG、FRESET、UART 线序或外设固件。
